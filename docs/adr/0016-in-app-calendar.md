# 0016. 行事曆只在 App 內，MVP 不與外部行事曆同步

- 狀態：已接受
- 日期：2026-11-07（2026-11-11 更新）

## 背景與問題

App 要依 task 在手機上的日 / 週 / 月曆標示任務。需要決定是否與 Google Calendar 等外部行事曆同步，以及旅遊行程如何出現在行事曆上。

## 考慮的選項

1. 只在 App 內
2. 與 Google Calendar 雙向同步
3. 單向寫入 Google Calendar

## 決策

- MVP 的 task 與行程**只存在本系統**，在 App 內以日 / 週 / 月曆檢視呈現，不與外部行事曆同步
- **旅遊行程**：行事曆上只顯示旅程期間；逐日逐時的細節只在旅遊頁查看（見 [0017](0017-travel-itinerary-planning.md)）

## 後果

### 正面

- 不需要額外的 Calendar OAuth scope
- 不需要處理同步衝突與重複事件
- 行事曆不會被旅遊的大量時段項目塞滿

### 負面 / 風險

- 用戶原有行事曆上的事件不會出現在 App 中，agent 安排時可能看不到既有行程
- 旅遊期間要切到旅遊頁才看得到當天的細節
- 之後若要加入同步，需要新的 ADR
