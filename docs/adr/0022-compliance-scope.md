# ADR-0022：法遵範圍——內測實作刪除與中斷、同意紀錄與隱私政策、DPIA

- 狀態：已接受
- 日期：2026-11-13
- 相關：ADR-0002、ADR-0003、ADR-0004、ADR-0005、ADR-0006、ADR-0017、ADR-0018、ADR-0021

> 本文件記錄的是產品與工程上的決定，不是法律意見。對外開放前應由具台灣個資法與 GDPR 專業的法律顧問審閱。

## 背景

產品的法遵目標是符合台灣個人資料保護法，並同時符合 GDPR。系統處理的資料特別敏感：

- 用戶的私人對話全文；
- 對話中其他人的訊息，這些人沒有同意、也不知道自己的訊息被處理（見 ADR-0003）；
- 資料會跨境：儲存在日本（見 ADR-0021），並送到美國由 LLM 供應商處理（見 ADR-0006）。

MVP 是 100 人以下的內測。需要決定內測階段要實作哪些用戶權利與法遵功能，哪些延到正式上線前。

## 考慮過的選項

四個項目逐一決定是否在內測實作：

1. 刪除帳號與中斷連結
2. 同意紀錄與隱私政策
3. 資料匯出
4. 資料保護影響評估（DPIA）

## 決定

內測實作第 1、2、4 項；第 3 項延到正式上線前。

### 1. 刪除帳號與中斷連結（內測實作）

- **中斷 LINE 連結**：用戶在 App 操作後，讀取服務立即停止該用戶的連線、登出 LINE 上的連結裝置、刪除保存的憑證。已保存的原始訊息預設一併刪除，task、行程、記憶保留（「一併刪除訊息」是預設假設，對齊時沒有確認）。
- **刪除帳號**：刪除該用戶的所有資料，包含原始訊息、task 與變更紀錄、提醒、行程、agent 記憶與對話紀錄、推播 token、LINE 憑證、官方帳號綁定。同意紀錄依法定需要保留的最小範圍另行處理。
- 刪除是硬刪除。備份中的資料在備份過期後消失，備份保存天數寫進隱私政策（見 ADR-0021）。
- 刪除帳號要求再次確認，完成後通知用戶。

### 2. 同意紀錄與隱私政策（內測實作）

- 每次同意都留存：用戶、時間、同意的項目、文件版本。項目包含：服務條款與隱私政策、LINE 非官方連線的風險告知（見 ADR-0002）、對話內容送交 LLM 處理與跨境傳輸。
- 文件改版後，要求用戶重新同意才能繼續使用對應功能。
- 隱私政策至少載明：
  - 蒐集的資料類別與目的；
  - 讀取範圍與用戶的控制方式（見 ADR-0003）；
  - 保存期限（見 ADR-0004）與備份保存天數；
  - 儲存地：日本（AWS 東京區域）；
  - 委外處理者與跨境傳輸：

    | 處理者 | 處理的資料 | 地點 |
    |---|---|---|
    | AWS | 全部資料的儲存與運算 | 日本 |
    | Anthropic | 送 LLM 處理的對話內容、task、agent 對話 | 美國 |
    | Google（Firebase Cloud Messaging） | 推播 token 與推播概述文字 | 依 Google 的處理地點 |
    | Google（Maps Platform） | 地點查詢字串與座標 | 依 Google 的處理地點 |
    | Google（OAuth） | 登入身分 | 依 Google 的處理地點 |
    | Apple（APNs） | iOS 的推播 token 與推播概述文字，由 FCM 轉送 | 依 Apple 的處理地點 |
    | LINE（LY Corporation） | 用戶與官方帳號 agent 的對話，包含 agent 回覆中的 task、行程與歷史訊息內容 | 依 LINE 的處理地點 |
    | Meta（WhatsApp Cloud API） | 用戶與 WhatsApp 官方帳號 agent 的對話，包含 agent 回覆中的 task 與歷史訊息內容（見 ADR-0024） | 依 Meta 的處理地點 |

  - 用戶的權利與行使方式、聯絡窗口。
- 與 Anthropic、AWS、Google、Meta 的資料處理協議（DPA）在內測開始前確認完成。

### 3. 資料匯出（延後）

- 內測期間，用戶的查閱與匯出請求由人工處理，隱私政策載明申請方式與回覆期限。
- **正式上線前必須做成 App 內的功能**。

### 4. 資料保護影響評估（內測前完成文件）

- 內測開始前完成 DPIA，並針對處理第三方對話內容做合法利益評估。
- DPIA 至少涵蓋下列已知的高風險項目：
  - 處理沒有同意的第三方對話內容，其法律依據（見 ADR-0003）；
  - 訊息與 LINE 憑證以明文保存（見 ADR-0005）；
  - 使用違反平台條款的非官方 client（見 ADR-0001）；
  - 對話內容跨境傳輸到美國（見 ADR-0006）；
  - 自動化判定（詐騙判定、task 抽取）的誤判影響（見 ADR-0008、ADR-0009）。
- DPIA 的結論若要求額外的緩解措施，以新的 ADR 記錄。

## 後果

### 正面

- 內測用戶可以隨時停止讀取並刪除自己的資料。
- 同意有紀錄可查，資料流向對用戶透明。
- 高風險項目在開始處理真實資料之前有書面評估。

### 負面與接受的風險

- **處理第三方對話內容的法律依據尚未確立**，這是本產品最大的法遵不確定性。DPIA 與法律審閱可能要求縮小讀取範圍或改變保存方式，進而推翻 ADR-0003、ADR-0004 或 ADR-0005。
- 第三方（對話中的其他人）沒有管道得知自己的訊息被處理，也無法行使權利。
- 資料匯出在內測期間靠人工，回覆速度取決於人力。
- 送給 LLM 供應商的資料無法在用戶刪除帳號時由我方主動刪除，依供應商的保留政策處理；需在 DPA 確認保留期限。

## 正式上線前必須補的項目

- 資料匯出功能。
- 重新檢視 ADR-0005 的儲存安全等級。
- 資料外洩的通報流程與應變計畫。
- 法律顧問對隱私政策、同意流程、DPIA 的審閱。
- 評估是否需要在歐盟指定代表，以及是否需要資料保護長；這取決於是否實際向歐盟境內的人提供服務。
