# 0024. 個資法遵與用戶同意：台灣個資法 + GDPR

- 狀態：已接受
- 日期：2026-11-11

## 背景與問題

系統會處理高度敏感的個人資料：

- 用戶的 email 與 LINE / WhatsApp 對話（包含群組中其他人的訊息）
- 與 agent 的對話紀錄、todo / schedule、agent 記憶
- 可等同用戶帳號完整存取權的 session 憑證

這些資料會交給多個處理者：Supabase、GCP、LLM 供應商，以及 Google Maps、Duffel 等外部 API。資料存放在東京（見 [0023](0023-environments-and-region.md)），不在用戶所在地。LINE / WhatsApp 採非官方讀取（見 [0009](0009-line-whatsapp-unofficial-read-only.md)），用戶的個人帳號有被封鎖的風險。

## 考慮的選項

適用法規：

1. 台灣個資法
2. 台灣個資法 + GDPR

綁定 LINE / WhatsApp 時的同意方式：

1. 綁定前獨立告知風險，用戶明確勾選同意
2. 寫在服務條款內，同意條款即視為同意

## 決策

- **適用法規**：系統依**台灣個資法**與 **GDPR** 設計
- **LINE / WhatsApp 綁定同意**：
  - 掃 QR code 前，獨立顯示風險說明：可能被平台封號、讀取範圍（含群組，見 [0009](0009-line-whatsapp-unofficial-read-only.md)）、只讀不發、不保存原始訊息（見 [0011](0011-no-raw-message-retention.md)）
  - 用戶須明確勾選同意才能綁定
  - 用戶可隨時解除綁定。解除時立即刪除該 session 的憑證
- **LLM 供應商**：只使用「不以客戶資料訓練模型」的商用 API 條款，並與每家供應商簽署資料處理協議（DPA）（見 [0013](0013-llm-provider-abstraction.md)）
- **對話紀錄的刪除**：與 agent 的對話紀錄保存到用戶刪除為止。用戶可刪除單筆或全部對話；刪除帳號時一併刪除（見 [0014](0014-personal-agent-shared-memory.md)）

## 後果

### 正面

- 依 GDPR 標準設計，日後擴展到其他地區時不必大改
- 用戶在承擔封號風險前，已被清楚告知

### 負面 / 風險

- GDPR 要求的權利（存取、更正、刪除、資料可攜）要實作在所有存放個資的地方：對話紀錄、todo / schedule、agent 記憶與 embedding、提醒、警告
- 資料存在日本，且由多個海外處理者處理，屬於跨境傳輸，需在隱私權政策中揭露，並以 DPA 等機制保障
- LLM 供應商在其條款的保留期間內仍持有資料
- 群組訊息含第三人資料，而這些人沒有同意過。GDPR 下需要合法處理依據（見待決）
